## 第 2 页　题型一　集合的基本运算　→　C

**题目**　M = {1, 3, 6}，N = {1, 3, 5, 7}，求 M ∩ N。

**思路**　交集就是"两个集合都有的元素"。逐个比对：1 在两边都有，3 在两边都有；6 只在 M 中，5、7 只在 N 中。

**解答**　M ∩ N = {1, 3}，选 **C**。

**板书提示**　可在下方写出两个集合的列举，用连线或打勾的方式标出公共元素 1、3。

## 第 3 页　题型二　不等式与集合运算　→　B

**题目**　A = {−1, 1, 2, 4}，B = {x | x² − 2x ≤ 0}，求 A ∩ B。

**思路**　先把 B 解出来：x² − 2x ≤ 0 ⟺ x(x − 2) ≤ 0 ⟺ 0 ≤ x ≤ 2，即 B = [0, 2]。
再把 A 中的四个数逐个检验是否落在 [0, 2] 内：−1 不在；1、2 在；4 不在。

**解答**　A ∩ B = {1, 2}，选 **B**。

**板书提示**　此题是"先解不等式、再验元素"的标准两步，建议左侧解不等式、右侧画数轴打点。

## 第 4 页　题型三　区间型集合运算　→　A

**题目**　A = {x | −2 < x < 2}，B = {x | −1 ≤ x < 3}，求 A ∪ B。

**思路**　A = (−2, 2)，B = [−1, 3)，二者在数轴上是"部分重叠"的关系（B 的右半段超出 A）。
并集取两者覆盖的全部范围：左端点由 A 提供 −2（不含），右端点由 B 提供 3（不含）；B 的左端 −1 落在 A 内部，被吸收。

**解答**　A ∪ B = {x | −2 < x < 3}，选 **A**。

**板书提示**　本题最适合画数轴。强调"并集看覆盖、交集看重叠"，端点开闭"取到就带、取不到就去"。

## 第 5 页　题型四　函数定义域与值域型集合　→　C

**题目**　A = {x | log₂ x < 1}，B = {x | 1 < x < 3}，求 A ∩ B。

**思路**　解对数不等式要注意**先定定义域 x > 0**。把 1 写成 log₂ 2，由 y = log₂ x 单调递增得
log₂ x < log₂ 2 ⟺ 0 < x < 2，即 A = (0, 2)。再与 B = (1, 3) 取交集。

**解答**　A ∩ B = (1, 2)，选 **C**。

**板书提示**　两个易错点：
①选 D = (0, 2)：**恰好是集合 A 本身**，说明算对了 A 却没有再与 B 取交集——这是本题最典型的失分点。
②忽略真数必须大于 0（把 A 写成 (−∞, 2)）在本题**不改变答案**，仍得 (1, 2)；但仍要借此强调"解对数不等式先写定义域"。
（数轴板演：把 (0, 2) 与 (1, 3) 画在同一条数轴上，重叠段即所求。）

## 第 6 页　题型五　特殊数集与列举法　→　C

**题目**　A = {x | x² − 4x ≤ 0}，B = {x ∈ N | |x| < 3}，求 A ∩ B。

**思路**　A：x² − 4x ≤ 0 ⟺ x(x − 4) ≤ 0 ⟺ 0 ≤ x ≤ 4。
B：|x| < 3 ⟺ −3 < x < 3，但 x 只能取**自然数**，故 B = {0, 1, 2}（不要漏掉 0）。

**解答**　A ∩ B = {0, 1, 2}，选 **C**。

**板书提示**　两个易错点：
①漏掉 B 中的 **0**（B = {0, 1, 2}）会得到 {1, 2}，落到选项 **B**——这是最常见的失分点，务必强调"0 是自然数"。
②本题对 ℕ、ℤ 的混淆**不敏感**：即使把 B 误当成 {−2, −1, 0, 1, 2}，因 A = [0, 4] 中不含负数，交集仍是 {0, 1, 2} = C。选项 D 中的 −1 只可能来自把 A 的解集下界算错（A 不可能含 −1），可用来反查学生的错因。

## 第 7 页　题型六　根据关系生成新集合　→　C

**题目**　A = {1, 2, 3}，B = {y | y = 2x − 1, x ∈ A}，求 A ∩ B。

**思路**　B 是用 A 的元素作"输入"、按 y = 2x − 1 生成的新集合，注意 B 中的元素是 **y 而不是 x**。
代入 x = 1, 2, 3 得 y = 1, 3, 5，故 B = {1, 3, 5}。

**解答**　A ∩ B = {1, 3}，选 **C**。

**板书提示**　强调"描述法的元素符号"，可写出三个对应关系 1→1、2→3、3→5，再对比 A 中元素。

## 第 8 页　题型七　集合关系与元素个数　→　D

**题目**　U = {1, 2, 3, 4}，A ⊆ B ⊆ U，求集合对 (A, B) 的个数。

**思路**　对 U 中**每一个**元素而言，它相对于 A、B 只有三种可能状态：
①不在 B 中（自然也不在 A 中）；②在 B 中但不在 A 中；③既在 B 中也在 A 中。
由于要求 A ⊆ B，第四种状态"在 A 中却不在 B 中"被排除。4 个元素各自独立选择，共 3 种，故有 3⁴ 个。

**解答**　3⁴ = 81，选 **D**。

**板书提示**　也可按 |B| 分类验证：B 含 k 个元素时有 C(4,k) 种，A 有 2^k 种，于是
Σ(k=0→4) C(4,k)·2^k = (1+2)⁴ = 81。两种讲法互为印证。

## 第 9 页　题型八　特殊元素与几何计数　→　5

**题目**　U = {(x, y) | x² + y² ≤ 1, x ∈ Z, y ∈ Z}，求 U 中元素个数。

**思路**　这是"圆内的整点"问题。x² + y² ≤ 1 且 x、y 都是整数，逐类列举：
- x = 0：y² ≤ 1 ⟹ y = 0, ±1，得 (0, 0)、(0, 1)、(0, −1)；
- y = 0：x² ≤ 1 ⟹ x = ±1，得 (1, 0)、(−1, 0)；
- |x| ≥ 2 或 |y| ≥ 2 时 x² + y² ≥ 4 > 1，无解。

（也可由 0 ≤ x² ≤ 1、0 ≤ y² ≤ 1 直接得到 x, y ∈ {−1, 0, 1}，再检验 9 个点：四角 (±1, ±1) 的 x²+y² = 2 > 1 舍去，恰余 5 个。）

**解答**　共有 **5** 个元素。

**板书提示**　建议在下方空白处直接画单位圆与 3×3 整数网格，让学生数出圆内（含边界）的格点，几何直观最强。
