第 1 题（幻灯片第 2 页）题型一：不等式与解集包含
原卷：第 63 题
正确答案：A　充分而不必要条件
------------------------------------------------------------------------
思路：
  条件 p：x² − 3x < 0  ⇔  x(x − 3) < 0  ⇔  0 < x < 3     记 A = (0, 3)
  条件 q：|x − 1| < 2   ⇔  −2 < x − 1 < 2  ⇔  −1 < x < 3   记 B = (−1, 3)
  因为 A ⊊ B（A 是 B 的真子集），所以 p ⇒ q，但 q ⇏ p。
  即 p 是 q 的充分不必要条件，选 A。
【板书要点】先解不等式化成解集，再用集合包含关系判断；
            小范围是大范围的充分条件。

第 2 题（幻灯片第 3 页）题型二：指数、对数与定义域
原卷：第 42 题
正确答案：A　充分不必要条件
------------------------------------------------------------------------
思路：
  p：log₂ x > log₂ y。对数有意义要求 x > 0 且 y > 0；
     又 y = log₂ t 在 (0, +∞) 上单调递增，故 p ⇔ x > y > 0。
  q：2^x > 2^y。指数函数 y = 2^t 在 R 上单调递增，
     且对一切实数都有意义，故 q ⇔ x > y。
  所以 p ⇒ q 成立；
  反之取 x = 1，y = −1，满足 x > y（q 成立），但 log₂(−1) 无意义（p 不成立），
  故 q ⇏ p。
  综上 p 是 q 的充分不必要条件，选 A。
【板书要点】做此类题先看"定义域"这一隐性条件——对数自带 x>0, y>0。

第 3 题（幻灯片第 4 页）题型三：代数运算与反例判断
原卷：第 40 题
正确答案：B　必要不充分条件
------------------------------------------------------------------------
思路：
  必要性：由 a² ≠ b² 能推出 a ≠ b。
          因为若 a = b，则 a² = b²（逆否命题：a² ≠ b² ⇒ a ≠ b 成立）。
          所以"a ≠ b"是"a² ≠ b²"的必要条件。
  不充分：取反例 a = 1，b = −1，此时 a ≠ b 成立，但 a² = b² = 1，
          所以由 a ≠ b 推不出 a² ≠ b²。
  综上"a ≠ b"是"a² ≠ b²"的必要不充分条件，选 B。
【板书要点】判断不充分最常用的手段就是举反例；注意 a² = b² ⇔ a = b 或 a = −b。

第 4 题（幻灯片第 5 页）题型四：函数单调性与参数范围
原卷：第 61 题
正确答案：A　充分不必要条件
------------------------------------------------------------------------
思路：
  f(x) = 2x² + 4ax + 1 是开口向上的二次函数，
  对称轴为 x = −(4a)/(2×2) = −a。
  f 在 (2, +∞) 上单调递增  ⇔  对称轴在区间左侧  ⇔  −a ≤ 2  ⇔  a ≥ −2。
  条件"a > −2"能推出 a ≥ −2（充分）；
  但 a = −2 时对称轴恰为 x = 2，f 在 (2, +∞) 上仍然单调递增，
  即 a ≥ −2 推不出 a > −2（不必要）。
  综上"a > −2"是充分不必要条件，选 A。
【板书要点】"在 (2, +∞) 上递增"→ 对称轴 ≤ 2（含等号）；
            端点等号能否取到，正是本题不必要的原因。

第 5 题（幻灯片第 6 页）题型五：三角函数与周期性
原卷：第 125 题
正确答案：A　充分不必要条件
------------------------------------------------------------------------
思路：
  充分性：若 x = 2kπ + π/6（k ∈ Z），
          则 sin x = sin(2kπ + π/6) = sin(π/6) = 1/2。充分。
  必要性：由 sin x = 1/2 得
          x = 2kπ + π/6  或  x = 2kπ + 5π/6 （k ∈ Z），
          例如 x = 5π/6 满足 sin x = 1/2，但不满足 x = 2kπ + π/6。不必要。
  综上选 A。
【板书要点】sin x = 1/2 在一个周期内有两解，第二象限那支就是反例来源。

第 6 题（幻灯片第 7 页）题型六：向量与几何关系
原卷：第 4 题
正确答案：C　充要条件
------------------------------------------------------------------------
思路：
  |a + b| = |a − b|
  ⇔ |a + b|² = |a − b|²
  ⇔ a·a + 2a·b + b·b = a·a − 2a·b + b·b
  ⇔ 4a·b = 0  ⇔  a·b = 0
  又 a、b 是非零向量，故 a·b = 0 ⇔ a ⊥ b。
  两个条件互相等价，是充要条件，选 C。
【板书要点】向量模的等式问题一律平方去模；
            本题"非零"是为保证 a·b = 0 与 a ⊥ b 完全等价。

第 7 题（幻灯片第 8 页）题型七：数列性质与条件判断
原卷：第 17 题
正确答案：B　必要不充分条件
------------------------------------------------------------------------
思路：
  必要性：若 {aₙ} 是等差数列，设首项 a₁、公差 d，
          则 a₂ + a₄ = (a₁ + d) + (a₁ + 3d) = 2a₁ + 4d，
             a₁ + a₅ = a₁ + (a₁ + 4d) = 2a₁ + 4d，两者相等。成立。
  不充分：取数列 a₁ = 1，a₂ = 2，a₃ = 10，a₄ = 3，a₅ = 4，
          此时 a₂ + a₄ = 2 + 3 = 5，a₁ + a₅ = 1 + 4 = 5，条件成立，
          但 a₂ − a₁ = 1，a₃ − a₂ = 8，不是等差数列。
  综上"a₂ + a₄ = a₁ + a₅"是"{aₙ} 为等差数列"的必要不充分条件，选 B。
【板书要点】等差数列只有 2 个自由度（a₁, d），而前 5 项有 5 个自由度，
            一个等式约束不住，必然不充分；举反例时直接构造即可。

第 8 题（幻灯片第 9 页）题型八：解析几何与直线关系
原卷：第 28 题
正确答案：A　充分不必要条件
------------------------------------------------------------------------
思路：
  l₁：x + 2ay − 1 = 0，l₂：(3a − 1)x − ay − 1 = 0。
  充分性：当 a = 0 时，
          l₁：x − 1 = 0（即 x = 1），l₂：−x − 1 = 0（即 x = −1），
          两条直线都垂直于 x 轴且不重合，故 l₁ ∥ l₂。充分。
  必要性：两直线平行（或重合）需系数行列式为 0：
          1·(−a) − 2a·(3a − 1) = 0
          ⇒ −a − 6a² + 2a = 0  ⇒ −6a² + a = 0  ⇒ a(1 − 6a) = 0
          ⇒ a = 0 或 a = 1/6。
          检验 a = 1/6：l₁：3x + y − 3 = 0，l₂：3x + y + 6 = 0，平行且不重合。
          所以 l₁ ∥ l₂ ⇔ a = 0 或 a = 1/6，由 l₁ ∥ l₂ 推不出 a = 0。不必要。
  综上"a = 0"是"l₁ ∥ l₂"的充分不必要条件，选 A。
【板书要点】含参直线问题必须讨论"斜率不存在"的情形；
            a = 1/6 这一支就是"不必要"的证据。

第 9 题（幻灯片第 10 页）题型九：逻辑综合与条件选取
原卷：第 59 题
正确答案：A　−2 < x < 1
------------------------------------------------------------------------
思路：
  x² < 1  ⇔  −1 < x < 1，记集合 A = (−1, 1)。
  题目要求使"x² < 1"成立的"必要不充分条件"，
  即找一个条件 C，使 A ⇒ C 但 C ⇏ A，也就是 A ⊊ C（A 是 C 的真子集）。
  逐项判断：
    A 项 (−2, 1)：A ⊊ (−2, 1)，A ⇒ C 且 C ⇏ A。 ✔ 必要不充分条件
    B 项 (−1, 1)：与 A 完全相同，是充要条件。            ✘
    C 项 (0, 2) ：与 A 互不包含。                        ✘
    D 项 (−1, 0)：是 A 的真子集，属充分不必要条件。       ✘
  故选 A。
【板书要点】"谁是谁的什么条件"统一转化为集合包含：
            小集合 ⇒ 大集合；"必要不充分"就是"真子集关系，方向为被包含"。
