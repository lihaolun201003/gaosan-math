                                   4 集合知识点系统总结

4.1 集合的基本概念

集合具有确定性、互异性、无序性。常用数集：

                      N = {0, 1, 2, . . .},    N∗ = {1, 2, 3, . . .},      Z, Q, R.

               / N∗ 。
特别注意：0 ∈ N，但 0 ∈
列举法直接列出元素，如 A = {1, 3, 5}；描述法通过条件描述，如 B = {x ∈ Z | −1 < x < 3} = {0, 1, 2}。
同一元素重复写并不产生新元素，例如 {1, 1, 2} = {1, 2}。


4.2 交集、并集、补集


      运算            定义                                                  一句话理解

      交集            A ∩ B = {x | x ∈ A 且 x ∈ B}                         同时属于 A 和 B

      并集            A ∪ B = {x | x ∈ A 或 x ∈ B}                         至少属于一个集合

      补集            ∁U A = U \ A                                        在全集 U 中，但不在 A 中

      差集            A \ B = A ∩ (∁U B)                                  属于 A，但不属于 B



 德摩根律：
                 ∁U (A ∪ B) = (∁U A) ∩ (∁U B),           ∁U (A ∩ B) = (∁U A) ∪ (∁U B).

 口诀：并的补等于补的交；交的补等于补的并。

计算交、并、补时，一定先确定全集。例如 U = {1, 2, 3, 4}，A = {1, 4}，则 ∁U A = {2, 3}，并不是全体
实数中去掉 1 和 4。


4.3 区间表示与端点规则


           (a, b) = {x | a < x < b},     [a, b] = {x | a ≤ x ≤ b},      [a, b) = {x | a ≤ x < b}.

严格不等号对应空心端点，含等号对应实心端点。遇到 A ∩ B：取公共部分；遇到 A ∪ B：合并覆盖区
域。请特别注意 (−2, 1] 与 [−2, 1] 是否包含 −2。

4.5 整数条件：先解范围，再筛元素

{x ∈ Z | −2 < x ≤ 2} = {−1, 0, 1, 2}；{x ∈ N | −2 < x ≤ 2} = {0, 1, 2}。
例如 A = [0, 4]，B = {x ∈ Z | |x − 1| ≤ 2}，则 B = {−1, 0, 1, 2, 3}，A ∩ B = {0, 1, 2, 3}。不能将有限集
合 {0, 1, 2} 写成连续区间 [0, 2]。


4.6 带参数的集合与子集


                                   A ⊆ B ⇐⇒ ∀x ∈ A, x ∈ B.

做 B ⊆ A 的参数题时，先把 B 中每个元素放到 A 中检查。集合元素不重复，因此 {1, a} 允许 a = 1，
此时集合仅有一个元素；若题目要求恰有两个不同元素，才需另加 a ̸= 1。


4.7 集合元素个数与子集计数

含 n 个不同元素的有限集合，共有

                      2n 个子集,        2n − 1 个非空子集,          2n − 1 个真子集.

若 |U | = n，满足 A ⊆ B ⊆ U 的有序集合对 (A, B) 有

                                               3n 对

因为 U 中每个元素有三种独立状态：不在 B；在 B 不在 A；在 A 也在 B。例如原题第 24 题的 |U | = 4，
所以共有 34 = 81 对。


4.8 天津高三集合题标准四步法

 1. 定对象：看清全集 U 、集合元素是数字还是数对，是否有 x ∈ Z、x ∈ N。

 2. 化集合：先解不等式、求定义域/值域或代入列举，化成数集/区间。

 3. 按顺序算：先括号，再交并补，必要时画数轴或韦恩图。

 4. 查端点：检查 <, ≤、是否取整、是否漏 0、是否把数对误写成数。
